## Movie Recommendation System

A smart movie recommendation platform that uses content-based filtering to deliver personalized movie suggestions through an interactive Streamlit interface.
##  Features

-  Movie recommendations using a similarity-based ML model
-  User registration and login using Supabase
-  Add and manage favorite movies
-  Watch history
-  Interactive Streamlit UI
-  Supabase database integration

##  Tech Stack

**Python | Streamlit | Machine Learning | Supabase | HTML/CSS**
